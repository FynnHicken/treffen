# Treffen – Der werbefreie Spieleabend

Komplettes, orchestriertes Paket für deinen Spieleabend-Server mit synchroner Party-Lobby, Live-Präsenz und 5 fertigen Spielen:
-  **skribbl** (Go)
-  **UNO** (Node.js)
-  **Codenames** (Python)
-  **Guess The Price** (React / Express / SQLite)
-  **Monopoly 3D** (FastAPI / Three.js)
-  **Mensch ärgere dich nicht** (3D-Spieltisch, FastAPI / Three.js)

---

## 🚀 Schnellstart

```bash
# 1. Starten
./start.sh

# 2. Im Browser öffnen
http://localhost:8000
```

---

## 🌐 Mit No-IP Domain & HTTPS starten

```bash
export MY_DOMAIN="deine-domain.ddns.net"
./start.sh
```

---

## 🛑 Beenden

```bash
./stop.sh
```
